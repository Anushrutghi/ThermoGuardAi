# Datasets

- `synthetic/` — generated by `python -m training.dataset_gen --samples N`.
  Contains `images/{train,val,test}` and `labels/` in YOLO format plus
  `dataset.yaml` ready for `ultralytics`.
- Generated outputs (from training runs) live in `datasets/generated/` and
  are git-ignored.

To build a real production dataset, replace the synthetic images with
labeled photographs of electrical panels (tools like Roboflow can export
YOLO format directly).
